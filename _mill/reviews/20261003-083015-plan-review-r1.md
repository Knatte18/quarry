### [NIT:consistency] Card 1 -run filter excludes the timing test
**Demoted-from:** BLOCKING
**Location:** Batch 1 / Card 1, step 3.
**Issue:** `-run 'Loomyard'` does not match `TestResolve_TwentyGlyphsUnder150ms` (`internal/engine/loomyard_timing_test.go`), so the line step 3 requires to read `PASS` never appears, and the card's "stop and report" rule can halt the batch on a healthy baseline.

### [BLOCKING:design] fileTargetAnswer target-only fileEntry derefs nil for a symlink
**Location:** Batch 1 / Card 3, `fileTargetAnswer` bullet.
**Issue:** In `toc.go` `fileTargetAnswer`, a symlink target is skipped before it reaches `fileEntries`, so `recs[targetBase]` is nil for it, and calling `r.fileEntry` "only for the target base" before the kept symlink branch dereferences `rec.err` (`TestRepoTOC_SymlinkTargetIsNameOnlyNotFollowed` in `repo_test.go` drives this path).
**Fix:** State that `fileEntry` is called only when the target is a non-symlink present in `recs`, with the symlink branch producing the name-only entry otherwise.

### [NIT:consistency] Card 3 commit leaves unused imports
**Location:** Batch 1 / Card 3.
**Issue:** Once `fileEntry` stops parsing, `walk.go`'s `unicode/utf8`, `ts` and `treesitter` imports, and `toc.go`'s `path/filepath` import (used only by the `dirLang` loop moving into `dirVote`), go unused, so card 3's commit does not compile.
**Fix:** Add card 4's "remove imports `go build` reports" instruction to card 3 for `walk.go` and `toc.go`.

### [NIT:consistency] Naming decision contradicts card 5 retargeting
**Location:** Overview "names after the refactor" vs. Batch 1 / Card 5.
**Issue:** The decision keeps `fileEntry`'s name so that `text.go`'s and `delta.go`'s references "stay pointed at the right function", but card 5 retargets both references to `buildRecord`.

### [NIT:consistency] resolveSelfTarget symbols-off rationale goes stale
**Location:** Batch 1 / Card 4, `resolveSelfTarget` doc bullet.
**Issue:** The doc comment's paragraph saying symbols are switched off so that each self target does not pay extraction cost becomes false: `newFileMemo(r, true)` extracts symbols for every record built on the self path, and the switch now only suppresses emission.
**Fix:** Have card 4 restate that paragraph as an emission rule, with the cost justification removed.

### [NIT:design] Clause-less fixture relies on unverified tree-sitter recovery
**Location:** Batch 2 / Card 6, test 3.
**Issue:** `toc_test.go`'s `packag mypkg` case proves only that the clause is lost; nothing shows that `func Lost` survives as a top-level `function_declaration`, which `goStrategy.Symbols` needs in order to emit it, and if it does not survive, the `cl#Lost` not_found assertion passes vacuously.
**Fix:** Tell the implementer to confirm the walk-side `cl#Lost` symbol first and to adjust the fixture if it is absent.

### [NIT:consistency] Round-trip doc says "same records"
**Location:** Batch 1 / Card 4, `roundtrip_test.go` bullet.
**Issue:** `harvestWalkSymbols` calls exported `TOC`, which builds its own memo, separate from the `newFileMemo` passed to `symbolsOfUnit`, so the two sides run the same extraction code over distinct records.
**Fix:** Word the comment as "the same extraction code" rather than "the same per-file records".

### [NIT:scope] Byte-identity goldens outside the engine package not run
