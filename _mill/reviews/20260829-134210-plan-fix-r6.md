## Fixed

- `20260829-133925-plan-review-r6.md` — "[NIT:consistency] `resolve_state_dir`'s `env` arg missing from its callers". Accurate: round 5 added the `env` argument to `resolve_state_dir` but not to the four helpers that call it, so none of them could satisfy it. - `20260829-133925-plan-review-r6.md` — "[BLOCKING:design] `gate_cold_before` keys on a file card 9 declares unreliable". Accurate, and it made the cold cell's own retry path unreachable: a failed attempt that had started a supervised daemon leaves its `daemon.json` behind — nothing removes the state file or its directory on exit, only `daemon.sock`, and only on the next spawn — so attempts 2 and 3 at the same worktree path would fail the precondition deterministically, in an outcome none of card 21's four dispositions covers. Fixed on both sides: added `daemon_alive`, defining a running daemon as a state file whose recorded pid is alive — the same staleness test quarry's own `daemonStale` applies — and rekeyed `gate_cold_before` onto it; and added `clear_state_dir`, which card 21 now calls before **each** attempt rather than only the first, so the precondition reads a directory this suite put in a known state. Added the retry case to the tests: a `daemon.json` present but recording a dead pid must pass (batch 3 card 9, batch 6 card 21).
- `20260829-133925-plan-review-r6.md` — "[BLOCKING:scope] Probe transcript has no declared path and is not gitignored". Accurate: card 18 recorded a transcript path that no card assigned, and anything written at the results root falls outside the one `results/**/raw/` pattern card 1 adds — so card 24's commit would have been dirty or would have committed a file absent from every `Creates:` and from All Files Touched. Placed it at `<results_root>/raw/probe/transcript.jsonl` and stated why that subtree specifically: it is the only one the ignore pattern covers, so the transcript stays untracked like every other per-run transcript while `probe.json` beside it stays tracked (batch 6 card 18).
