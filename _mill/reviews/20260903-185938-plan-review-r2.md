## Findings

### [NIT:consistency] extend/trim count contract is unusable as written
**Demoted-from:** BLOCKING
**Location:** batch 2 card 8 vs batch 3 card 17 **Issue:** card 8 declares `extend(dirRel string) error` recording the appended count *internally*, but `trim(n int)` takes the count explicitly and card 17 requires `walkDir` to "call `ig.trim` of the same count" — the caller is never given `n`. **Fix:** pin one shape (either `extend` returns the count, or `trim()` pops an internal frame stack) and state it in card 8; batch 2's "external interface batch 3 consumes" list also omits `trim` entirely.

### [BLOCKING:scope] Card 17 Context omits golang.go while naming goStrategy
**Location:** batch 3 card 17 **Issue:** `Requirements:` names `goStrategy.Package` (in `dirPackage`) and `goStrategy.PackageDoc` (in `dirDoc`), but `internal/engine/golang.go` is in neither `Context:` nor `Edits:` — the implementer cannot read the method it must call. **Fix:** add `internal/engine/golang.go` to card 17's `Context:`.

### [BLOCKING:design] SpansOf's ignore-set chain is under-specified
**Location:** batch 5 card 32, batch 6 card 38 **Issue:** card 32 says SpansOf "extends it along the root-to-unit-directory chain", which contradicts card 18's explicit root-to-*parent*-only convention, is silent on the `_test`-stripped directory of `unitDirs` rule 2, and cannot cover the two-directory collision case where one chain must serve two dirs; card 38 then calls `symbolsOfUnit(unit, ig)` directly without saying how the round trip builds `ig` at all. **Fix:** state inclusively which directories' `.gitignore` files are extended per `unitDirs` branch, and give card 38 the same rule for its own set.

### [BLOCKING:design] testdata/units/root.go is not an unspellable unit
**Location:** batch 4 card 30 **Issue:** the card calls `testdata/units/root.go` one of "the two unspellable-unit cases", but from the repository root its unit is `internal/engine/testdata/units`, which `glyph.Parse` accepts — only the space-bearing sibling is genuinely unspellable, so the asserted "neither carries `symbols`" fails as written. **Fix:** state that the empty-unit case is exercised by `Open`-ing `internal/engine/testdata/units` as its own repository root and querying `"."`, or drop `root.go`.

### [NIT:consistency] Task-level verify runs no tests
**Demoted-from:** BLOCKING
**Location:** 00-overview `verify:` and the "every batch leaves the tree building" Shared Decision **Issue:** the module-wide `verify:` is `CGO_ENABLED=1 go vet ./...` alone, so the task's own done-criterion — the quarry round trip and the Loomyard goldens, both plain Go tests — is never exercised by the final gate, only by per-batch verifies. **Fix:** make the task `verify:` the same build-vet-test triple batch 6 uses.

### [NIT:consistency] The walk bypasses the Strategy registry
**Location:** batch 3 card 17 (`dirPackage`, `dirDoc`) **Issue:** both name `goStrategy` concretely rather than resolving through `StrategyFor(lang)`, hardcoding Go into the walk that batch 4's own scope calls "the alphabet is chosen per file, never per repository". **Fix:** route through `StrategyFor` and state that Go is the only registration today.

### [NIT:design] Root-level external test package yields the unit "._test"
**Location:** batch 4 card 25 **Issue:** `unitFor` maps the root's `dirRel` `"."` to the empty (unspellable) unit, but the external-test branch returns `dirRel + "_test"` = `"._test"`, which `glyph.Parse` accepts as a legal segment — so root-level `_test` files would be emitted under a unit the card's own gap statement says is undecided. **Fix:** say the root's external-test unit is unspellable too, or record it explicitly as the same open gap.
