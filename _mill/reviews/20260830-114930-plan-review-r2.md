## Findings

### [BLOCKING:design] ExtractFencedJSON drops the block/inner distinction
**Location:** batch 1 card 7; consumed by cards 30, 40, 58
**Issue:** `extract_fenced_json` returns `(block_text, inner_text)` and both halves are load-bearing — `_first_fenced_json_block` (schema_for) returns *block_text with fences*, which `preamble_for` embeds as the measured stimulus, while `_extract_fenced_json` and `_extract_answer` use *inner_text*; card 7's `ExtractFencedJSON(text, which string) (string, error)` returns one unnamed string, so card 40 or card 30 must re-derive the other half.
**Fix:** specify a two-value return (block and inner) in card 7 so cards 30/40/58 each name which half they take.

### [NIT:decision] No path carries gate observations into run.json
**Demoted-from:** BLOCKING
**Location:** batch 5 cards 24/23, batch 12 card 61, batch 7 card 31, batch 12 card 63
**Issue:** the non-fatal observations (`worktree_dirtied`, `target_origin_quarry_mention`, `cold_no_daemon_backed_call`) are now written into `ingest.json` by the run session, but `run.json` is written by `record-score` in the scoring session and no card says it reads them back; card 31 states "the ingest marker is invisible to summarisation", and both `runJSONObservations` / `daemon_backed_runs` / `CompareWarmCold`'s all-no-daemon-call suppression and card 63's `ColdCellDisposition` read those observations off `run.json`.
**Fix:** state in card 61 (or card 23's `WriteRunJSON` payload) that the ingest record's observations are copied into `run.json`, or retarget card 31/63 at `ingest.json`.

### [NIT:decision] "exhausted attempt record" is never defined
**Demoted-from:** BLOCKING
**Location:** batch 5 card 25 (`CheckSingleFlight`)
**Issue:** the third disjunct of the single-flight predicate names an artifact no card creates or defines — card 24's `Invalidate` only errors at the ceiling and card 59's `invalidate` only prints/halts, so nothing writes an exhaustion marker and the card's own test ("passing once any of the three conditions is met") has no state to construct.
**Fix:** define it concretely (e.g. `MaxAttempts` `<n>.invalid-<k>` siblings present) or name the file that records it and the card that writes it.

### [NIT:decision] Cold not-run cause has no on-disk source
**Demoted-from:** BLOCKING
**Location:** batch 12 card 63; batch 11 card 53
**Issue:** `ColdCellDisposition(l, resultsRoot)` must keep "the same not-run cause distinction between a live daemon before start and an exhausted native fallback", but under the session split the live-daemon cause is a `prepare-session` abort (card 53) that writes no artifact, and the Python tracked it only in in-session memory.
**Fix:** name the file `prepare-session` writes on a cold-before failure, or drop the cause distinction and say so in card 63.

### [BLOCKING:design] Correlation glob under-specifies the subagent path
**Location:** batch 12 card 57 (`LocateTranscript`)
**Issue:** the card says only "under the project directory derived from the session's working directory"; the actual layout on this machine is `~/.claude/projects/<mangled-cwd>/<session-uuid>/subagents/agent-<id>.meta.json` with the transcript as an `agent-<id>.jsonl` sibling — a non-recursive glob at the project directory matches nothing, and a recursive one spans every prior session under that cwd, which interacts with the "more than one match is a hard error" rule.
**Fix:** fix the exact glob pattern in card 57 the way batch 10's scope section fixes the skill roots and session-input filenames.

### [NIT:consistency] "nine validation rules" miscounts LoadLadder
**Location:** batch 1 scope + card 2 (title, requirements, commit message)
**Issue:** `load_ladder` has twelve `_fail` sites and the card's own enumeration lists eleven clauses, so the count is wrong wherever it is repeated.
**Fix:** drop the number or correct it; the enumeration is already authoritative.

### [NIT:consistency] GateReport accessors attributed to the Python
**Location:** batch 3 card 13
**Issue:** the card asks for "the same aggregate accessors the Python dataclass exposes (whether any fatal finding is present, and the fatal and non-fatal subsets)"; the Python `GateReport` exposes only `passed`.
**Fix:** state the two subset accessors as additions rather than as ports.

### [NIT:scope] Card 26's Context omits settings.go
**Location:** batch 5 card 26 (`RunGates`)
**Issue:** `run_gates` derives denied names through `deny_list_for`, whose Go counterpart `DenyListFor` lives in `settings.go` (card 5), which is not in the card's `Context:` or `Edits:`.
**Fix:** add `bench/loomyard-eval/ladder/internal/ladder/settings.go` to card 26's `Context:`.

### [NIT:design] Model-pinning gate's empty-transcript outcome unstated
**Location:** batch 3 card 15
**Issue:** the card requires a test for "a transcript with no assistant record at all" but never says whether that is a fatal finding or an error; the Python raised `StopIteration` from `next()`.
**Fix:** state the expected outcome in the requirements.
