## Fixed

- **[BLOCKING] "MaxAttempts is not a stop condition across invocations."** Verified: `InvalidateRep`
  derives its counter from the `.invalid-<k>` directories already on disk, so a resumed invocation's
  first attempt at a thrice-invalidated repetition trips `attempts >= MaxAttempts` (`run.go:419-425`)
  after having spent a fresh measured call, and neither `summary.json` nor the exit code separates
  "never attempted" from "exhausted". Fixed in `resume-not-restart`: the driver caps itself at three
  invocations per root and, before each re-invocation, counts `<root>/raw/<cell>/<rep>.invalid-*` —
  three or more means attempt-exhausted, and a root whose every missing repetition is exhausted is
  not re-invoked at all. Scope bullet 3 restated to match.
- **[BLOCKING] "Same-day harness-fix restart collides with the fixed root name."** Verified:
  `ReadProvenance` + `MergeProvenance` + `RepIsComplete` make a re-invocation against the same path a
  resume, not a restart. Fixed in `harness-fixes-restart-the-matrix` (the `-r2` suffix rule, the
  abandoned root never re-passed to `--results`, `ABANDONED.md` naming fix/date/successor) with a
  cross-reference added to `results-root-name`.
- **[NIT, demoted] "Scorer-failed and max-turns repetitions have no disposition."** Verified: both
  are written `complete`, so `RepIsComplete` is true and resume never revisits them;
  `summarizeCell` drops the unscored one from `recall`/`precision` only. Fixed in
  `resume-not-restart`: both are accepted, never retried, and the conclusion must print the
  correctness `n` (`recall_n`, `precision_n`, `MAX_TURNS`/`UNSCORED` flags) separately from the cost
  `n` and never claim "recall unchanged" without naming its `n`.
- **[NIT] "`TestLive` is a full measured repetition, not cheap insurance."** Verified: it calls
  `invokeMeasuredProcess` with the ladder file's own model, effort and 60-turn ceiling. Fixed: the
  cost is stated plainly in both `probe-is-reported-done` and Testing, and `-timeout 20m` is now
  explicit.
- **[NIT] "`probe.md`'s cited source of record dies at merge."** Verified against HANDOFF's
  squash-merge convention — the same cleaning that made T6's probe evidence unfindable. Fixed:
  `probe.md` cites `archive/ladder-toc-rerun:_mill/reviews/...` rather than a bare `_mill/` path.
- **[NIT] "'worktree root' names two different directories."** Verified: `cd <worktree-root>` meant
  the quarry git worktree while `<worktree-root>/bin/quarry` meant `ResolveWorktreeRoot`'s output,
  and the two are disjoint by construction. Fixed: "quarry repo root" and "ladder worktree root" used
  consistently at all six sites.
