## Fixed

- r1 "Embedded `entryRaw` hijacks every entry's decode" — verified accurate: Go promotes an
  embedded type's `UnmarshalJSON` to the outer type, so every declared field would decode to its
  zero value. Batch 3 card 13 now specifies a per-type unexported `raw json.RawMessage` field plus
  the type's own `UnmarshalJSON` decoding into a locally-declared alias, and explicitly forbids the
  embedded-helper form. Cards 15 and 17 updated to follow that convention; batch 3's Batch Scope
  interface list updated; card 13's test list now asserts every exported field is populated.
- r1 "`symbolField.Kind` typed `string`, source is `int`" — verified against
  `internal/quarryengine/query/symbol.go`, which declares `Kind int`. Batch 2 card 9 now declares
  `Kind int` with the reason stated.
- r1 "toc marshal-failure disposition unstated" — batch 5 card 22 now states that a
  `cli.StructToFields` or `cli.TOCDirEntries` failure is that entry's `statusError` carrying the
  message verbatim, and that `rewordMarshalFailure` is `impact`-only. Card 23 gained the matching
  assertion.
- r1 "`jsonschema-go` cannot become a direct v0.4.3 requirement as written" — batch 2 card 6 now
  names `go get github.com/google/jsonschema-go@v0.4.3` explicitly alongside the SDK `go get`.
- r1 "`workspace_symbol` gains an `ambiguous` branch the CLI has not" — verified against
  `internal/quarryengine/query/symbol.go`, whose `symbolFromClient` deliberately returns every
  match rather than collapsing to `ErrAmbiguousSymbol`, so the branch would be dead code. Fixed
  more strictly than the finding proposed: batch 2 card 9 now declares a separate
  `classifySymbolError` with no `ambiguous` branch, batch 3 card 15 routes through it, and
  `symbolMatchEntry` no longer declares a `candidates` key it cannot emit. Card 16 asserts the
  absence.
- r1 "Card 25 asserts wording the SDK owns" — batch 6 card 25 now asserts only the observable
  contract (error flag set, no handler run, no silent truncation) and explicitly excludes the
  validator's message wording.
- r1 "Card 10 Context omits `internal/cli/tocconfig.go`" — added to batch 2 card 10's `Context:`.
  `internal/quarryengine/query/symbol.go` added to card 9's `Context:` for the same reason, since
  the `classifySymbolError` rationale now cites it.
