## Fixed

- `[BLOCKING:scope]` "Card 17 Context omits golang.go while naming goStrategy" — verified: card 17
  called two `goStrategy` methods with the file in neither `Context:` nor `Edits:`. Fixed twice
  over: `internal/engine/golang.go` added to `Context:`, and both call sites now resolve through
  `StrategyFor(lang)` rather than naming the concrete strategy (see the registry NIT below).
- `[BLOCKING:design]` "SpansOf's ignore-set chain is under-specified" — verified: card 32 said
  "root-to-unit-directory chain", which contradicts card 18's root-to-parent convention, said
  nothing about the suffix-stripped directory, and could not serve the two-directory collision.
  Card 32 now pins the division exactly: the caller supplies a set carrying the root's own patterns
  only, and `symbolsOfUnit` extends and trims the chain **per directory, inclusive of that
  directory**, because nothing descends here — so `walkDir`'s "the caller owns everything above me"
  split does not apply. Card 38 now builds its set the same way, in one clause.
- `[BLOCKING:design]` "testdata/units/root.go is not an unspellable unit" — verified: from the
  quarry root that file's unit is `internal/engine/testdata/units`, which `glyph.Parse` accepts, so
  the asserted "neither carries symbols" would have failed. Card 30 now splits the two cases by
  entry point: the bad-rune case is queried from the quarry root as usual, and the empty-unit case
  `Open`s `internal/engine/testdata/units` as its own repository root and queries `"."`. `root.go`
  is kept, since it is exactly the file that case needs.
- `[NIT:consistency]` "extend/trim count contract is unusable as written" — verified: `extend`
  recorded the count internally while `trim(n)` demanded it from a caller that was never given it.
  `extend` now returns `(n int, err error)`; card 17 holds the returned count and passes it to
  `trim`. Batch 2's external-interface list gains `trim` and names batch 5 as a consumer too.
- `[NIT:consistency]` "Task-level verify runs no tests" — verified: the module-wide gate was
  `go vet` alone, so the round trip and the goldens — the task's own done-criterion — were never
  exercised by it. The overview `verify:` is now the same build-vet-test triple batch 6 uses, and
  the Shared Decision says why.
- `[NIT:consistency]` "The walk bypasses the Strategy registry" — verified: `dirPackage` and
  `dirDoc` both named `goStrategy` concretely. Both now resolve through `StrategyFor(lang)`, with a
  comment stating Go is merely the only registration today.
- `[NIT:design]` "Root-level external test package yields the unit `._test`" — verified:
  `glyph.Parse` accepts `._test` as a legal segment, so root-level `_test` files would have been
  emitted under a unit while their same-directory siblings were excluded. `unitFor` now returns the
  empty string for **both** branches at the root, and card 25 states that this is the same recorded
  gap rather than a second rule.
