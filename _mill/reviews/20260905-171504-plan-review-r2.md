## Findings

### [BLOCKING:design] Depth-target probe names no --root and no binary

**Location:** batch 3 / card 14, first paragraph
**Issue:** The probe is spelled `quarry toc --depth 1 <candidate>` with no `--root .scratch/loomyard-pin` and no invocation form; the repo builds the CLI at `cmd/quarry/main.go` and nothing puts a `quarry` binary on PATH. Verified in `internal/cli/cli.go`: `Run` step 4 calls `repopath.ResolveRoot(req.root, cwd)` and `runTOC` calls `repopath.RepoRelTarget(root, base, req.target)`, so with no `--root` the candidates resolve against the **quarry** repo, where `internal/reedengine`, `internal/shedadapters` and `internal/fabricengine` do not exist — all three would answer `target not found` (exit 1) and the probe would silently fall through to `.`, the quarry root.
**Fix:** Spell the probe command in full, including how the CLI is invoked and `--root .scratch/loomyard-pin`, so the probe reads the same repository the golden generation does.

### [BLOCKING:scope] Candidate list likely exhausts to the unbounded fallback

**Location:** batch 3 / card 14, candidate order + size bound
**Issue:** Checked against the clone at `/home/knatte/Code/loomyard/wts/loomyard` (HEAD, not the pin `72c23d9` — directory shape may differ there): `internal/shedadapters` has **no** subdirectory at all, so it can never satisfy "a `dirs` entry that itself carries `files`"; `internal/reedengine` has one (`render/`) but ~30 own `.go` files plus `render/`, which at `--depth 1` with the view's implicit `--symbols` very likely blows the ~200-line bound; `internal/fabricengine` is far larger still. The operative rule therefore becomes the terminal clause, "the smallest subdirectory of `.` that has a subdirectory of its own" — which defines neither "smallest" (files? symbols? golden lines?) nor a tie-break, and does not re-apply the 200-line bound.
**Fix:** Make the terminal clause as specific as the ordered list it replaces (a stated size metric, a tie-break, and the same bound), since it is the branch the plan will in practice take.
